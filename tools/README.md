# note 自動投稿ツール

note には公式の投稿APIがないので、**ブラウザを自動で動かして**投稿します（Playwright を使用）。

## 準備（最初の1回だけ・自分のPCで）
1. Node.js をインストール（https://nodejs.org）
2. このリポジトリを開いて `npm install` → `npx playwright install chromium`
3. `npm run note:login` → ブラウザが開くので、いつもどおり note にログインし、ターミナルに戻って Enter
   - ログイン状態は `.note-auth.json` に保存されます。パスワードはどこにも保存しません。

## 投稿
- 下書きとして保存: `npm run note:draft -- note/2026-11-nonfryer-potato.md`
- 公開は note の画面で内容を確認してから、自分で「公開に進む」を押してください（自動公開はしない運用）

終わると `note-result.png` に画面のスクリーンショットが保存されます。

## 記事ファイルの書き方
- 1行目の `# ...` がタイトル
- `## 見出し`、`**太字**`、`・` / `-` / `1.` のリスト、`> 引用`、URL に対応
- 最後の `#タグ #タグ` の行はハッシュタグとして扱います（公開時に入力）

## 注意
- note の画面が変わると動かなくなることがあります。動かないときはエラーメッセージとスクリーンショットを Claude に見せて直してもらってください。
- 自動操作は note の利用規約上グレーになる可能性があります。投稿は1日数本程度にとどめ、まずは下書き保存で使い、公開ボタンは自分で押すのが安全です。
